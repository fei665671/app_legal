## 如何发布

在仓库根目录提交并推送：

```bash
cd ~/Desktop/salat-now-legal
git add PhoneDrive-Legal
git commit -m "Add PhoneDrive privacy policy"
git push
```

推送后等 1–2 分钟再打开上面的 URL。
