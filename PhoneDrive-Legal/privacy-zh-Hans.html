隐私政策

手机U盘（PhoneDrive）· iPhone、iPad、Mac · 最后更新：2026 年 8 月 17 日 · 联系：luolin0231@gmail.com

手机U盘（以下简称「本应用」「我们」）是一款在你的设备之间传输、存放和播放文件的工具。我们不运营云端账号，也不把你的文件或个人信息上传到我们的服务器。请在使用前阅读本政策。

1. 我们不向开发者收集数据

本应用：

  • 不要求注册或登录；
  • 不使用分析、广告或崩溃统计 SDK；
  • 不做跨 App 追踪（NSPrivacyTracking = false）；
  • 不把文件、相册、PIN、设备名称或使用记录发送给我们。

App Store 隐私标签中对应的申报是：不收集数据。本政策中的「处理」均发生在你的设备上，或发生在你主动连接的局域网 / USB 链路对端设备上。

2. 仅保存在本机的信息

下列信息只写在本机系统提供的存储中（例如 App 沙盒、Application Support、UserDefaults），用于让应用正常工作：

信息用途
自定义设备名称在接收界面和局域网页上显示，便于对端识别
传输 PIN、端口局域网 / USB 传输时校验访问
欢迎页是否完成记住是否看过引导
保险柜开关与本地密码校验值判断隐藏文件夹是否已设置、是否允许生物识别
本机 Bonjour 实例标识仅用于局域网发现，不是账号
文件库索引（文件名、大小、文件夹、是否隐藏等）在本机列出和管理你导入或接收的文件
文件内容本身保存在本应用容器内，供你查看、播放、再传出

卸载本应用后，上述本机数据会随 App 容器一并删除（系统另有备份的除外）。

3. 系统权限

本应用只在你使用相应功能时请求权限，可随时在系统设置中关闭。

本地网络 — 用于在同一 Wi-Fi 或 USB 网络上发现设备，并在你开启「开始接收」后提供本机网页与文件传输。关闭后，局域网发现和网页互传将无法工作。

Face ID / 触控 ID（及设备密码）— 仅用于解锁你设置过的隐藏文件夹。系统在本机完成识别，我们无法读取你的面容、指纹或生物识别模板。

相册 — 仅在你主动从相册导入照片或视频时使用。导入的是你选中项目的副本，写入本应用文件库；不会在后台扫描整本相册，也不会把相册内容上传到我们的服务器。

用户选择的文件（尤其是 Mac）— 发送、导入、下载保存时，通过系统文件选择器 / 保存面板访问你指定的路径。我们不会在未获你选择的情况下读取磁盘上的其他文件。

4. 文件如何在设备之间传输

传输由你发起，路径是同一 Wi-Fi 下的局域网，或 USB 数据线形成的个人热点 / 链路本地网络。

本应用在接收端开启一个仅局域网可达的 HTTP 服务（默认端口 8787，可在设置中修改）。浏览器或 Mac 客户端通过该地址上传或下载。对端需要你在接收界面上显示的 PIN。

请注意：

  • 文件在链路上以 HTTP 明文传输，不经过我们的云，但同一网络中若有人同时知道地址和 PIN，则可能访问当前共享会话中的内容；
  • 请使用你信任的网络，传输结束后请及时停止接收或刷新 PIN；
  • 带「访客隔离 / AP 隔离」的 Wi-Fi 可能无法互发现。

局域网发现可能通过 Bonjour 广播设备名称、服务端口等信息，范围限于当前网络，不会发到公网。网页通道（Android、Windows、未安装本应用的电脑）同样只连到你手机或电脑当时显示的本地地址，不经过我们的服务器。

5. 隐藏文件夹与生物识别

隐藏文件夹用于在本机文件库中收起你标记为隐藏的项目。未解锁时，本机界面以及对端（Mac / 网页）的文件列表都不会露出这些内容。

这是本机可见性控制，不是文件级加密：文件仍以普通文件形式存在于本应用容器中。请勿将其理解为「加密保险柜」或端到端加密存储。

用于解锁的密码校验信息保存在本机。生物识别由 iOS / macOS 系统 API 完成。

6. 播放与 AirPlay

你在本应用内播放的视频、图片均来自本机文件库。若你使用系统 AirPlay 投到电视或其他设备，内容由 Apple 系统传送到你选择的播放设备，我们不中转、不存储该流转。

7. 第三方

除 Apple 提供的系统能力（App Store 分发、Face ID / 触控 ID、AirPlay、本地网络等）外，本应用不含第三方统计、广告、登录或云存储 SDK。Apple 作为平台运营方，其处理适用 Apple 自己的隐私政策。

8. 未成年人

本应用不以儿童为主要对象，也不故意收集儿童的个人信息。因我们不向开发者收集数据，亦不提供面向儿童的账号。若你是监护人并认为未成年人在设备上保存了不适宜内容，请在本机删除相关文件或卸载应用。

9. 保留、删除与你的选择

  • 本机删除：在文件库中删除文件或卸载应用。
  • 停止共享：在接收界面停止接收，或刷新 PIN。
  • 权限：在系统设置中关闭本地网络、相册或 Face ID。
  • 向我们删除数据：我们的服务器上没有你的个人数据可删。若你通过邮件向我们发送问询，该邮件本身由邮件服务商按常规存储，处理完毕后我们不会将其用于其他目的。

10. 安全

我们采取与产品形态相符的措施，例如：传输需 PIN、隐藏夹在解锁前不对端可见、文件保留在系统沙盒中。局域网 HTTP 并非针对不可信网络设计的加密通道。请自行判断使用场景，不要在不信任的公共网络上开启接收。

11. 你的权利

在适用的数据保护法律下，你可能享有知情、访问、更正、删除等权利。由于我们不保存可识别你的云端档案，这些权利主要通过你在本机操作实现。你仍可通过文末邮箱联系我们。我们不会出售你的个人信息。

12. 政策更新

功能若发生变化（例如增加云同步、账号或分析），我们会更新本政策，并视情况在应用或本页面提示。请以本页「最后更新」日期为准。
